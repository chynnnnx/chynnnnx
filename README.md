## About Me

Most of my projects start as something I want for myself, then grow into something more polished. I like working across the whole stack — building the API, wiring up the UI, and setting up the pipeline that ships it — and I care about writing code that's easy to come back to six months later.

- 🔭 Currently building full-stack apps with **.NET**, **Angular**, and **Blazor**
- 🌱 Sharpening my C# fundamentals — certified in *Foundational C# with Microsoft*
- 🛠️ From desktop tools with WinForms to modern SPAs and REST APIs
- ⚙️ Into CI/CD pipelines that make shipping boring (in a good way)
